# Set up EAS Build for HabitFlow

**Chapter 16 — From Expo Go To A Real App**  
Used in: Step 3

---

```
Set up EAS Build for HabitFlow:

1. Install expo-dev-client (this enables the development build to have developer tools like hot reload)

2. Run eas build:configure to create the eas.json configuration file

3. Make sure the eas.json has three profiles:

- development: for testing on my device (includes developer tools)

- preview: for sharing with beta testers (no developer tools, but not optimized)

- production: for the app stores (fully optimized)

4. Show me the final eas.json file
```
