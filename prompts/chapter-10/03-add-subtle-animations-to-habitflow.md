# Add subtle animations to HabitFlow

**Chapter 10 — Design System And Visual Polish**  
Used in: Step 4

---

```
Add subtle animations to HabitFlow:

1. When a checkbox on the Today Screen is toggled, animate a quick scale bounce on the checkmark (scale to 1.2 then back to 1.0 over 200ms)

2. When the progress ring on Today updates, animate it smoothly

3. A small confetti burst animation when all habits for the day are completed (use simple animated dots, no external library)

4. The floating + button should have a gentle breathing pulse animation

5. Screen transitions should use smooth slide animations Use React Native's built-in Animated API. Keep all animations under 300ms for interactions.
```
