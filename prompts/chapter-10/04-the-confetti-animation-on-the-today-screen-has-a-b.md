# The confetti animation on the Today Screen has a bug

**Chapter 10 — Design System And Visual Polish**  
Used in: Step 5

---

```
The confetti animation on the Today Screen has a bug. It plays every time the screen is displayed, not just when the user completes the last habit. For example, if all habits are already completed and the user navigates to Settings and back, the confetti plays again. Fix this so the confetti only triggers at the exact moment a checkbox is toggled that causes all habits to become completed. It should not trigger when the screen loads and habits are already all complete from a previous session or a previous visit to the screen.
```
