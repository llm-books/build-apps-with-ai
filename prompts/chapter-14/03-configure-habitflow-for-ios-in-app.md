# Configure HabitFlow for iOS in app

**Chapter 14 — Platform Specific Setup**  
Used in: Step 3

---

```
Configure HabitFlow for iOS in app.json:

1. Set bundleIdentifier to com.habitflow.app

2. Set buildNumber to "1"

3. Add Info.plist permission strings for camera and notifications (user-friendly explanations)

4. Configure splash screen matching Android

5. Set supportsTablet to true

6. Add dark mode support with infoPlist UIUserInterfaceStyle to "Automatic"
```
