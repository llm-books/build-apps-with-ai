# Habits I create on my phone do not appear on my tablet,…

**Chapter 21 — Troubleshooting Common Issues**

---

```
Habits I create on my phone do not appear on my tablet, even though I am logged in with the same account. Check the Firestore sync logic and make sure the real-time listener is set up correctly. Also check that the Firestore security rules allow reads for the correct user path.
```
