# Create an app icon for HabitFlow

**Chapter 15 — Platform Specific Setup**

---

```
Create an app icon for HabitFlow. Design a simple, modern icon with a checkmark inside a circular progress ring on a solid purple (#6C3483) background. The checkmark should be white and bold. The progress ring should be a lighter purple or white arc, about 75% complete, suggesting ongoing progress. Export it as a 1024x1024 PNG file with no transparency. Keep the design minimal, it should be recognizable at 20x20 pixels.
```
