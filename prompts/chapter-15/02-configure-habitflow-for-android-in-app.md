# Configure HabitFlow for Android in app

**Chapter 15 — Platform Specific Setup**  
Used in: Step 2

---

```
Configure HabitFlow for Android in app.json:

1. Set package name to com.habitflow.app

2. Set versionCode to 1 and version to "1.0.0"

3. Configure adaptive icon with purple (#6C3483) background and a monochrome icon layer for Android 13+ themed icons

4. Configure splash screen with purple background

5. Set up notification icon

6. Add permissions for camera and notifications

7. Configure status bar (light-content style)
```
