# Prepare HabitFlow for a production release

**Chapter 17 — Publishing To The Google Play Store**  
Used in: Step 2

---

```
Prepare HabitFlow for a production release:

1. Make sure eas.json has a production profile for Android that outputs an AAB file

2. Remove the temporary "Test Notification" button from the Settings screen

3. Remove the "Generate Test Data" button from the Settings screen if it exists

4. Make sure all console.log statements are removed from production code

5. Verify the app version in app.json is set to "1.0.0"
```
