# Set up Git for HabitFlow

**Chapter 8 — Saving Your Work With Git**  
Used in: Step 2

---

```
Set up Git for HabitFlow:

1. Initialize a Git repository in the project (git init)

2. Create a .gitignore file that excludes: node_modules, .expo, dist, build folders, .env files, and any files that should not be tracked (use a standard React Native .gitignore template)

3. Make the first commit with the message: "Initial commit: HabitFlow with Today Screen, Add Habit Screen, and data persistence"

4. Show me how to connect this to a remote GitHub repository
```
